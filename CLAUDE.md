## UI Development Rules

For ANY task involving UI, UX, frontend design,
styling, layouts, or visual components:

- Automatically use the installed Impeccable skill.
- Do not require the user to explicitly request it.
- Follow Impeccable's design principles throughout.

### Required Workflow

1. Before implementation:
   - Apply Impeccable's design guidance.
   - Review existing UI patterns and design context.

2. During implementation:
   - Build the requested UI changes.
   - Maintain design system consistency.
   - Avoid generic AI-generated aesthetics.

3. After implementation:
   - Apply Impeccable's critique methodology.
   - Identify visual and UX weaknesses.
   - Apply polish improvements where appropriate.
   - Perform an accessibility and design audit.
   - Fix relevant issues before completing the task.

Apply this workflow automatically for every UI
change without requiring additional prompts.

Do not run this workflow for backend-only changes.
